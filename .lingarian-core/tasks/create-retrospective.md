# Create Retrospective

## Task Description

Create learning documentation and retrospective files to capture insights, challenges, and improvements from completed work. Focus on analyzing what could have been done better and identifying root causes of issues or delays.

## Task Objectives

1. **Analyze What Could Be Improved** - Identify specific areas where work could have been done better
2. **Root Cause Analysis** - Determine why issues occurred (missing documentation, wrong tools, poor decisions, etc.)
3. **Document Learning** - Capture key insights and lessons learned for future reference
4. **Process Enhancement** - Identify concrete improvements to prevent similar issues

## Retrospective Focus Areas

### Improvement Analysis
- What specific aspects could have been done better?
- Which decisions or approaches led to suboptimal outcomes?
- What alternative solutions or methods would have been more effective?

### Root Cause Investigation
- **Documentation Gaps** - Was information missing, unclear, or outdated?
- **Tool Selection** - Were inappropriate tools or technologies chosen?
- **Decision Quality** - Were earlier decisions flawed or based on incomplete information?
- **Process Issues** - Did process failures contribute to problems?
- **Knowledge Gaps** - Was lack of expertise or understanding a factor?
- **Communication Breakdown** - Were there misunderstandings or poor information flow?

### Learning Extraction
- Key technical insights gained during the work
- Process improvements that would prevent similar issues
- Better practices or approaches discovered
- Knowledge that should be documented for future teams

## Output Requirements

Create retrospective file in `docs/learnings/` directory with filename format:
`YYYY-MM-DD-agent-name-story-name.md`

## Quality Standards

- Use clear, objective language focused on improvement opportunities
- Include specific technical details and concrete examples
- Document actionable insights with implementation suggestions
- Perform thorough root cause analysis for each identified issue
- Focus on learning and continuous improvement rather than blame
- Provide specific recommendations for preventing similar problems
