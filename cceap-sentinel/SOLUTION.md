# Solution Overview

## Problem Statement

Describe here the problem that CCEAP Sentinel addresses.

## Approach

- **Monitors** continuously watch target resources/services for drift or issues.
- **Validators** apply rule-based checks against monitored data.
- **Remediation** modules take corrective action when validation fails.
- **Notifications** alert stakeholders about detected issues and remediation outcomes.
- **Models** define shared data structures used across the system.
- **API** exposes functionality for integration with other systems or a UI.
