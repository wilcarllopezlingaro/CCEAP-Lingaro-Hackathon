# Tables

## Purpose
Display structured data with options for sorting, filtering, and quick actions.

## Anatomy
- Container: full width of content area (up to 960 px), background #FFFFFF.
- Column headers: background #F6F7F9, text Maven Pro, 14 px, Medium, color #000000.
- Cells: text Manrope, 14 px, Regular, color #000000.
- Dividers: 1 px lines #E1E2E4.
- Extra elements: action icons (24 px) in right-aligned cells.

## Variants
- Simple table (data only).
- Table with actions (icons/buttons in rows).
- Table with statuses (chips inside cells).

## Row States
- Default: background #FFFFFF.
- Hover: background #F6F7F9.
- Selected: light purple background #EBDCF4.
- Disabled: text #757779.

## Specs
- Row height: 44–48 px.
- Vertical cell padding: 12–16 px.
- Minimum click target for icons: 44×44 px.

## Usage
- ✅ Headers must always be visible and readable.
- ✅ Add sorting/filters when needed.
- ❌ Don’t overload rows with too many icons or actions.
- ❌ Don’t use tables for very small datasets (<3 rows).
