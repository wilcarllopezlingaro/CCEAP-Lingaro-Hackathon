# Divider

## Purpose
Used to visually separate content or groups of elements in the interface.

## Anatomy
- Line 1 px across the full width of the container or block.
- Color: light gray #E1E2E4.

## Variants
- Horizontal divider (default).
- Vertical divider (for tables, menus, cards).

## States
- Default: color #E1E2E4.
- Hover/Active: no change.

## Specs
- Thickness: 1 px.
- Top/bottom spacing: 16–24 px (depending on context).
- Height (for vertical): 100% of container.

## Usage
- ✅ Use to logically separate blocks.
- ✅ Combine with spacing, not as the only visual accent.
- ❌ Don’t overuse dividers — they may overload the interface.
- ❌ Don’t replace headings or grid structure with dividers.
