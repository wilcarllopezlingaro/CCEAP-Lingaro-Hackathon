# Callouts / Banners

## Purpose
Used to display system messages, statuses, or tips directly within the content.

## Anatomy
- Container: rectangle with 1 px border.
- Background: light shade of the chosen color.
- Border: stronger shade of the same color.
- Text: Manrope, 14 px, Regular.
- Icon (optional): 20–24 px on the left.
- Actions (optional): button or link on the right.

## Variants
- Success
- Error
- Warning
- Info

## States
- Success: background #E9F7EA, border #38B13C, text #054B07.
- Error: background #FDECEA, border #E2302D, text #8A0C0C.
- Warning: background #FFF9E0, border #FABD29, text #6C4E00.
- Info: background #EBDCF4, border #662E90, text #3E1B55.

## Specs
- Height: 48–64 px.
- Inner padding: 12–16 px.
- Icon–text spacing: 8 px.
- Text–button spacing: 16 px.

## Usage
- ✅ Use light backgrounds with contrasting text.
- ✅ Place callouts at the top of content or sections.
- ❌ Don’t overload a page with multiple callouts.
- ❌ Don’t use callouts as permanent interface elements.
