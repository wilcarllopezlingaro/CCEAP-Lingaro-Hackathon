# App Structure (Desktop only, Light)

## Main Layout
- Top App Bar fixed at the top, contains logo, product name, and main actions.
- Content area centered, max width 960 px, with consistent padding.
- Tabs below the App Bar for switching between main sections (up to 5).
- Content blocks inside: tables, cards, forms, dialogs.
- Footer/status strip optional, for auxiliary information.

## Layout Principles
- Single-column grid, 960 px wide, 24 px side padding.
- Vertical rhythm between blocks: 24 px.
- Unified system of corner radii, shadows, and spacing.

## Navigation
- Primary navigation via Top App Bar and Tabs.
- Secondary navigation via buttons and links inside content.

## Content Types
- Lists and tables for data.
- Cards for visual previews and grouped content.
- Forms for data input and editing.
- Dialogs for confirmations and quick actions.
## Theme

- Light version only.
- White/light gray background, purple accent color.
- Fonts: Maven Pro (headings, buttons), Manrope (body text).
